## 一、选型理由（调研结论）

| 候选 | 结论 |
|---|---|
| **ECharts 5.5.1**（选用） | 一套库覆盖全部所需图型：折线/柱状/环形/雷达/仪表盘/词云(echarts-wordcloud)/知识图谱网络(force graph)/effectScatter 点位脉冲；Vue3 兼容成熟，离线可用，社区最大 |
| **@kjgl77/datav-vue3 1.7.4**（已装备用） | Vue3 版大屏组件库（科技边框/装饰/滚动表格），后续想换更重的科技感边框可直接引入，v1 用自研 CSS 面板（更贴合项目印章式角标风格） |
| DataV(@jiaminghi) / vue-big-screen | 仅支持 Vue2，排除 |
| SkillHub/GitHub 现成 skill | 检索无高质量大屏技能（唯一相关项相关度 0.05、24 次下载，Vue2 专用），不引入 |

**适配方案**：1920×1080 固定舞台 + `transform: scale()` 等比缩放（大屏标准做法，任何屏幕/投影不变形）。

## 四、演示切换方式

- 浏览器打开 **`http://localhost:5173/bigscreen`**
- **键盘 `1` / `2` / `3`**：直接跳屏；**空格**：暂停/恢复轮播；**双击**：全屏
- 右上角页签点击可手动切屏；默认每 **30 秒**自动按 1→2→3 轮播
- URL 直达指定屏：`/bigscreen?screen=2`

## 五、接入真实接口步骤（只改 1 个文件）

`frontend/src/views/bigscreen/data/provider.js`：

1. `DATA_SOURCE = 'api'`
2. 在 `REAL_API` 表中核对每个 key 的端点（文件内已写好建议端点映射，
   例如 `kgStats → GET /api/guide/graph`、`contentAssets → GET /api/admin/guide/metrics`）
3. 若后端字段名不同，在 `adaptMap` 里做字段映射——视图层认的是 mock 同名结构，永不变
4. 接口失败自动回落 mock，大屏永不空白

轮询节奏：实时数字 5s / 图表 30s / 日志 8s（`POLL` 常量）。
